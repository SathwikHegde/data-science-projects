# ML Data Cleaning and Feature Selection

## Overview

This project demonstrates effective **data cleaning** and **feature selection** techniques, which are foundational steps in any machine learning pipeline. The notebook walks through the preprocessing workflow to prepare raw data for modeling by identifying and handling inconsistencies, missing values, irrelevant features, and noisy data.

---

## Objective

Prepare a raw dataset for machine learning by:
- Cleaning missing or inconsistent data
- Encoding categorical variables
- Scaling/normalizing numeric features
- Selecting relevant features using statistical and model-based methods

---

## Tools & Technologies

- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook

---

## Data Cleaning Techniques Used

- Null value handling (mean, median, mode imputation)
- Outlier detection and removal
- Data type corrections
- Duplicate removal
- Encoding categorical features
- Data normalization/scaling

---

## Feature Selection Methods

- Univariate feature selection (SelectKBest)
- Recursive Feature Elimination (RFE)
- Feature importance using tree-based models
- Correlation heatmaps

---

## Results

- A refined dataset with only the most relevant and clean features
- Improved interpretability and performance for downstream ML models
- Strong foundation for building predictive models with higher accuracy
